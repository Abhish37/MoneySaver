## [0.1.0-alpha] — 2026-07-22

### Added

- **Project Initialization**: Created the `d:/Money Saver` root project directory and established the full folder scaffold including `/docs`, `/scripts`, and `/.github/workflows`.
- **Product Requirements Document (PRD)**: Wrote `docs/PRD.md` from user-provided product specification. Covers problem statement, target personas (Rohan, Ananya), all 9 feature specifications, user stories, out-of-scope boundaries, and success KPIs.
- **README.md**: Corporate-grade project readme with status badges, problem/solution table, feature priority table, KPI table, tech stack placeholder table, project directory tree, and getting started instructions.
- **LICENSE**: MIT License for year 2026, attributed to MoneySaver Contributors.
- **CHANGELOG.md**: This file. Follows Keep a Changelog 1.1.0 format with Semantic Versioning.
- **CONTRIBUTING.md**: Full contributor guide covering bug reporting, feature requests, Git branch naming conventions (`feat/`, `fix/`, `docs/`, `chore/`), Conventional Commits format, PR checklist, and code review process.
- **CODE_OF_CONDUCT.md**: Contributor Covenant v2.1 — full text.
- **SECURITY.md**: Responsible disclosure policy with supported versions table, 48-hour SLA, 90-day coordinated disclosure timeline, and listed security practices.

- **`.gitignore`**: Comprehensive ignore rules for Node.js, Python, OS files, IDE files, environment secrets, log files, and coverage reports.
